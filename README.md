# きる あそび (kiru-asobi)
ハサミで切ることを、画面と台紙で練習する遊び。
参考：療育の実践書（「ハサミを使用する」の課題を参考にした）。この仕様は、同書の考え方をもとに、私たちが画面用に解釈した試作です。
- 画面：色紙の点線を、●（切り始め）から★（止まる所）まで指でなぞる。なぞると切れ目ができ、★まで行くと紙が切り落とされる。「どこを切るか」が分かっているかを確かめる。
- 台紙：初めて切れると印刷ボタンが出る。いまの場面の台紙を A4 で印刷し、本物のハサミで切る（大人の記入欄つき。アプリには記録しない）。
- 場面：1回切り／連続切り（短い 約5cm・長い 約10cm）／曲線／円。紙を折る、は作らない。
- 支援者メニュー・手助け・とめる/おしまい・くわしく・お祝いの強さは、他のアプリ（かく あそび等）と同じ構成。
- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。名前・記録は保存しない。カメラ・マイク不使用。
- 設計：docs/spec.md
