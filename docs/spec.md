# きる あそび 仕様（kiru-asobi）（第2版）
参考：療育の実践書（「ハサミを使用する」の課題を参考にした）。この仕様は、同書の考え方をもとに、私たちが画面用に解釈した試作です。

## 0. 考え方
- 画面では、ハサミで切る動きは判定しない（画面でできないことは、大人が見る）。
- 画面で確かめるのは「どこを切るか」の理解：どこから切り始め（●）、どこを通り（点線）、どこで止まるか（★）。
- 実際に切る練習は、印刷した台紙を、本物のハサミで切る。次の場面へ進むかは、紙を切った結果で大人が決める。
- 「紙を折る」は作らない（折り紙で、現場で日常的に行われているため。2026-11-03 決定）。

## 1. 画面（子どもの画面は文字なし）
- 色紙の上に、切る線（点線）がある。紙の下の端に ●（切り始め、緑の大きな丸）、線の終わりに ★（止まる所）。
- 子どもは、●に指を置き、★まで、線をなぞる。なぞった所に切れ目（すき間）ができ、進むと「ちょき」と小さな音が鳴る。
- ★まで行くと、切れた紙が落ちて、星と音（お祝いの強さは支援者が選ぶ）。
- 指が線の近くにあると、線がやわらかく光る。指の位置に、指で隠れない大きさの輪を出す（かく あそびの「なぞる」と同じ）。
- 切れ目は、いまの切れ目の先からだけ伸びる。★の側から逆になぞったり、線から離れたりしても進まない（いやな音や示しは出さない）。

## 2. 場面（やさしい順）
| 場面 | 画面 | 台紙（A4） |
| --- | --- | --- |
| 1回切り | 細長い紙を、端から1本ずつ切り落とす | 高さ2cmの帯×7本、3cmごとに切り線（線の長さ 約2cm） |
| 連続切り | 長い線を、途中で止まらずに切る | 線の長さ「短い 約5cm」（帯3本）／「長い 約10cm」（2枚） |
| 曲線 | なだらかなS字の線 | 18×6cmの紙×3、S字の切り線 |
| 円 | 紙の端から入り、円をひと回り | 8cm四方×4、半径2.5cmの円と入り口の線 |
- 1回切り・連続切りは、同じ紙を続けて切る（端から1本ずつ落ちる）。紙が短くなると、新しい色紙になる。
- 線の長さの数字は、決まった基準ではない。他のAIの助言（短い線から段階的に伸ばす）にもとづく、実装上の目安。

## 3. 台紙の印刷（支援者用）
- 画面で初めて切れると、下の列（とめる・おしまいの横）に、印刷のボタンが出る。支援者メニューの「台紙を印刷する（A4）」からも開ける。
- 押すと、確認の画面（支援者用、文字あり）が出る。「印刷する」で、いまの場面の台紙を A4 で1枚印刷する（子どもが間違えて押しても、すぐには印刷されない）。
- 台紙には ●（切り始め）と ★（止まる所）を印刷する。
- 台紙の下に、大人の記入欄：「できた 1枚目○ 2枚目○ 3枚目○／手助け 大・ふつう・小／日付」。アプリには記録しない（観察記録の方針 案A と同じ）。
- 次の場面へ進む目安：紙の上で、3枚中2枚ほど切れたら（目安。大人が見て決める）。

## 4. 支援者メニュー（他のアプリと同じ構成）
- 場面（絵つき4つ：1回切り／連続切り／曲線／円）
- この場面：線の長さ（連続切り：短い 約5cm／長い 約10cm）、台紙を印刷する（A4）、つぎの紙にする
- みんな共通：手助け（大きい＝線から少し離れてもなぞったことになる／ふつう／小さい＝線の上を正確に）
- くわしく：場面の説明、触れ方、見た目、お祝いの強さ（なし／控えめ（初期値）／ふつう／派手）、音、説明をもう一度
- もとにもどす／とじる。画面の下に「とめる」「おしまい」（他のアプリと同じ）

## 5. 約束（他のアプリと同じ）
- 子どもの画面に文字を出さない。点滅なし。音はやわらかく、音量は支援者が調節。
- 名前・記録・声・顔・録音を保存しない。カメラ・マイクは使わない。治療効果をうたわない。
- 説明画面に、実践書の留意点（使わない手は大人が軽く押さえる、はじめは大人がハサミを開いて紙を挟む、切りやすい固さの紙、ストローや粘土での1回切り）を書く。

## 6. 未決
- 台紙の線の長さ・紙の幅：現場で使って、合わなければ調整する。
- 曲線・円の大きさの段階（今は1種類）。

## 7. 確認（2026-11-03）
- Playwright（iPad縦横・iPhone縦横・SE）：4場面（連続切りは短い・長い）で、●から★までなぞると切れて紙が落ちる、線から離れると進まない、逆になぞっても進まない、1回切り・連続切りは同じ紙の次の線へ続く、印刷ボタンが初めての成功で出る、台紙5種類の印刷表示、エラーなし。
- 実機（iPhone・iPad）と、実際のプリンターでの印刷は未確認。
