# きる あそび 仕様（kiru-asobi）（案）
出典：『認知発達治療の実践マニュアル』Stage I「6-3 制作の基礎」（p.43〜44）、図3 1回切り・図4 連続切り・図5 半分折り。

## 1. 目的
- 画面は、ハサミで切る動きを判定しない（画面でできないことは、大人が見る）。
- 画面でできること：「どの線を切るか」の指示が分かっているかを確かめる（選ぶ）。
- 実際に切る練習は、印刷した台紙を、本物のハサミで行う。

## 2. 段階（本の順）
1. 1回切り：まっすぐな線を、1回の開閉で切る（図3）。
2. 連続切り：間隔の広い線から、数回の開閉が必要な線を切る（図4）。
3. 曲線・円：なだらかな曲線、そして円を切る（④）。
4. 紙を折る：半分まで折る。折り目の線と、四隅の印を合わせる（図5）。

## 3. 画面（子どもの画面は文字なし）
- 上に「手本の線」（切る線の形）を出す。下に、選択肢の紙（2つか3つ）を並べる。
- 子どもが、手本と同じ線の紙を指で選ぶ。
- 合えば、星と小さな音。違えば、音も示しもせず、選択肢を薄くして戻す（失敗を強調しない）。
- 3つ合うと、次の手本へ。

## 4. 印刷（A4の台紙）
- 支援者メニューの「台紙を印刷する」で、いま選んでいる段階の台紙を、A4に3枚印刷する。
- 1回切り・連続切り：細長い紙に、切り線（点線）。連続切りは切り線の間隔を広め→狭めに並べる。
- 曲線・円：なだらかな曲線と円の切り線。
- 紙を折る：正方形に、折り目（点線）と、四隅の印（点）。

## 5. 支援者メニュー（右上の点を1.2秒長押し）
- 段階（4つ）、選択肢（2／3）、台紙を印刷する。
- くわしく：画面の説明、本の留意点（紙の固さ、ストローや粘土での練習、大人が見本を示す）。

## 6. 約束
- 名前・記録・声・顔・録音は保存しない。カメラ・マイクは使わない。治療効果をうたわない。
- 紙を切る判定は、大人が見て行う（画面には表示しない）。
